About Roommate Finder

A web application created for the 3rd-semester mini project to resolve student housing and compatibility challenges.

🎯 The Problem Statement

Every academic semester, thousands of college students relocate away from home. Finding affordable accommodation near universities is difficult, but finding a compatible, trustworthy roommate is even harder.

Mismatches in sleep schedules (night owls vs. early birds), dietary restrictions (vegetarian vs. non-veg), budget limits, and study environments often lead to unnecessary disputes, stress, and broken leases during crucial exam periods.

💡 Our Solution: Roommate Finder

Roommate Finder bridges this gap by offering a college-centric matching platform. Instead of relying on random social media posts or expensive brokers, students can search for verified peers and filter candidates across crucial compatibility criteria:

  • Budget Transparency: Match only with students whose monthly rent capacity aligns with yours.
  • Food Habits Alignment: Filter pure-veg or non-veg preferences for kitchen peace.
  • Study Routines: Align exam study timings and sleep cycles.
  • Campus Proximity: Filter accommodations by specific university zones.

🛠️ Project Architecture & Final Integration

Full-Stack Architecture (Phase 5 Complete)

Built using HTML5, Vanilla CSS3, Vanilla JavaScript on the client, backed by Node.js & Express REST APIs with secure session management, and a relational MySQL database with parameterized queries and bcrypt password encryption.

✓ Fully Integrated & Tested

Deterministic Matching Algorithm

Rule-based, explainable 100-point compatibility score rubric evaluating Location (20pts), Budget overlap (20pts), Diet (15pts), Study habits (15pts), Sleeping schedule (10pts), Smoking habits (10pts), and Cleanliness (10pts).

❓ Frequently Asked Questions

Is this web app responsive on mobile devices?

Yes! The CSS layout utilizes Flexbox, CSS Grid, and media queries to ensure smooth usability across phones, tablets, and desktop displays.

Does this project store data in MySQL?

Yes. The project uses MySQL with relational tables (`users` and `student_profiles`), foreign keys with ON DELETE CASCADE, unique email indexing, and bcrypt hashed passwords.

Can a student search without creating an account?

Yes, students can freely browse and filter roommate cards on the search page. Creating an account allows listing their own preferences and calculating personalized compatibility scores.
